# 简易相似图片查找工具

[English](README.md) | [中文](README.zh-CN.md)

基于感知哈希的相似图片查找工具

## 功能

- 以文件夹为基础的图片相似性计算+比较
- 相似图片自动分组+标记
- 相似图片下载+删除
- 内置图片预览功能

## 快速开始

### 环境要求

- windows 10+
- Node.js 20+
- npm

### 运行

```
git clone https://github.com/SSSSShogun/A-Simple-Similar-Image-Finding-Tool-With-Web-UI.git

cd image-similarity

npm install

npm run build

npm start

在浏览器访问 http://localhost:3000
```

### 使用

#### 输入区

![输入](./docs/输入.png)

- 点击“添加文件夹”添加图片;或点击“添加文件夹”添加图片；或新建.env文件并输入“IMG_ROOT=路径1；路径2”（以";"隔离）
- 点击菜单图标查看/移除文件夹
- 点击语言缩写切换中/英文

#### 结果区

![输入](./docs/结果.png)

- 点击“配置”更改采样尺寸、相似阈值等参数
- 点击“计算相似”开始计算
- 手动点击相似组图片的右下角将图片标记为已选择
- 点击“自动标记”按文件要素自动标记相似图片
- “清除选择”会将所有图片标记为未选择
- “下载所选“会下载所有已选择图片
- ”删除所选“会删除所有已选择图片（移至回收站）

## 性能

配置：14700k@4.8Ghz关超线程，32GB DDR4@3866Mhz；工具使用至多8个worker

- 未加载任何图片时内存占用约100MB
- 加载2225张图片共6.2GB，完成缩略图加载约10s，缩略图完全加载后占用约400MB；大核心占用满，小核心占用不到一半
- 以128（最大）采样大小计算相似性，占用同上，耗时约40秒

注：默认电源设置可能让计算跑在小核心上（AMD YES!），更改电源计划或将终端置于前台可解决。
